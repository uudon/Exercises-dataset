# Iteration 7 Task 6 changes

Date: 2026-10-07

## Scope

Task 6 records offline, lifecycle, performance, body-resource, and release-gate evidence. The body report/parser, runtime validators, mapping tests, verification task, manifest metadata, and iteration-7 reports were updated. Existing user changes outside that scope were preserved.

## Changes

- `tools/verify-offline-contract.sh` now rejects remote/network markers in Kotlin and Java production code, network media dependencies, and non-local paths in the media and body manifests.
- `tools/verify-body-models.sh` now includes generated mesh, triangle, selectable-mesh, and required-region statistics in its JSON output and cross-checks generated byte counts.
- `BodyModelCheckReport` and `model-check-report.json` separate runtime/structure validity from release authorization; the report records actual GLB structure metrics while retaining `valid: false` and `licenseStatus: blocked`.
- `BodyMappingValidator` and `MuscleActionMapper` keep technically valid action mappings available while exposing `releaseAuthorizationBlocked`; malformed model structure remains blocking.
- Iteration-7 reports and project checklists distinguish passed, blocked, and not-run evidence.

## Preserved requirements

The app continues to require local packaged resources, explicit manifest checksums, resource/update/user-data preservation, and a release block until model authorization is formally confirmed. No remote fallback or placeholder authorization was added.
